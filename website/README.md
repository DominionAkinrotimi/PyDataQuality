# PyDataQuality website

The public landing page. Vite, React, TypeScript, Tailwind and Motion.

```bash
npm install
npm run dev      # local preview with live reload
npm run build    # writes dist/
```

Pushing to `main` deploys it to GitHub Pages (see `.github/workflows/site.yml`).

The files in `src/components/magicui` come from [Magic UI](https://magicui.design) (MIT), as listed on 21st.dev.

Rules for the copy: no customer logos, testimonials or user counts until they are real, a source for every number, and the product's limits stated on the page.
